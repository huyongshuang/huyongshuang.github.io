Screen Color Picker

Use the EyeDropper API to extract colors from anywhere on the screen, supporting conversion of multiple color formats.

#dee2e6

After clicking the button, your mouse will turn into a dropper; click any position on the screen to get the color value.

Color Formats

Format Value Action

1. Click the "Open Color Picker" button, your mouse will become a color dropper;

2. Click any spot on the screen to retrieve its color value;

3. Click the "Case" button next to the HEX color to switch uppercase and lowercase HEX code;

4. Click the "Copy" button beside each color format to copy the color code to clipboard.

Screen color picking tool built on EyeDropper API | Supports HEX, RGB, HSL, HSV, CMYK and other formats
